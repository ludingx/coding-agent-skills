# Session pickup

**Own the resume point. Read the prior trail, then continue from it.** Do not redo completed work just to reconstruct the same state.

1. **Locate the prior trail.** Use a transcript from the active workspace, a cloud-agent URL, or a pushed branch. Read metadata and the latest messages first, then scan back to the decisions that explain the current state. Do not search transcripts from other workspaces.
2. **Reconstruct the operational state.** Check the branch, worktree, landed changes, uncommitted diff, open todos, and recorded decisions. Treat the prior trail as the starting point, not a substitute for checking the current repository state.
3. **Compare completed work with the plan.** Identify what is done, what remains, and the exact resume point. Do not repeat a completed repro or redo a completed change unless current evidence shows it is necessary.
4. **Route the remaining work.** Continue with the matching playbook. If the work is complete, report the result. If a prior conclusion needs review, name that as the task. If the previous run failed, use the relevant investigation or bug-fix workflow.
5. **Verify inherited claims against the real artifact** using **principle-prove-it-works**. A previous self-report is not proof.

Hand back: where the prior agent stopped, what you inherited and verified, what you did not repeat, the resume point, and the outcome.

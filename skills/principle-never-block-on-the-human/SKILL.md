# Never Block on the Human

Make reasonable decisions on reversible work, proceed, and let the human course-correct after seeing the result.

Permission pauses stall work. Reversible changes are reviewable, so a wrong execution choice usually costs less than waiting for approval.

- Proceed with reversible execution choices and explain them in the hand-back.
- Fix problems you discover in the next work unit when it is within scope.
- Pause before irreversible actions such as force-pushing a shared branch, deleting production data, or sending external messages.
- Ask the human to make product-direction decisions. Do not block on routine execution choices.

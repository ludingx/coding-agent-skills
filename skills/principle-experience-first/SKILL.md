# Experience First

When implementation convenience conflicts with user experience, choose the better experience.

- Justify every feature, control, and option.
- Ship fewer polished features instead of more rough ones.
- Prototype design decisions before committing to production code.
- Get transitions, alignment, spacing, feedback, and error states right.
- Keep the core user workflow focused.

The user may be an end user, a colleague importing a library, or the engineer maintaining the code. Weigh the experience from the perspective of the people who use and maintain the result.

Foundational Thinking governs the sequence of work. This principle governs the target experience.
